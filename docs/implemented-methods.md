# Implemented methods and interpretation

This records the executable implementation, including its current approximations. It does not assert that every requirement of the implementation goal is complete.

The observed target is the difference of cell means after the declared expression transformation. For count inputs the transformation is `log1p(10000 * counts / library_total)`, using every available input gene for the denominator before exact source/recipient gene intersection. These are differences of normalized-log means, not raw-count log fold changes. Different released gene panels can change the compositional denominator; the external comparison must disclose that limitation.

Source responses for every retained intervention, including recipient queries, are public. Centering these response vectors across interventions and eigendecomposing their intervention-by-intervention Gram matrix produces source-only PCA coordinates. Selected coordinates have unit RMS and an intercept is appended. No recipient expression selects genes or coordinates. Source half-sample differences and mean-variance estimates are retained as uncertainty diagnostics; current fitted intervals do not propagate that uncertainty.

Let `x_i` denote a candidate's coordinates and let the recipient effect satisfy `delta_i = x_i B` under the ideal model. If perturbation means have variances `v_i / n_i` and a shared control mean has variance `v_0 / n_0`, effect errors have covariance `C = diag(v_i / n_i) + (v_0 / n_0) 11'`. Information for response slopes, accounting for the unknown baseline, is the weighted centered scatter of treatment features and the zero control feature. The implementation computes that scatter without subtracting nearly equal matrices. A factored GLS solve avoids catastrophic precision cancellation. These are classical calculations, not novel theorems.

Identification is evaluated before ridge: a query must lie in the numerical row space of the unregularized information matrix. Unsupported queries receive infinite ideal variance. This is linear-model algebra, not identification of biological transportability. Source-coordinate error, omitted mechanisms, selection/survival, batches, guide effects and structural bias can invalidate the response model even when its algebraic rank is full.

Every policy receives the same public source summaries and the same paid pilot: recipient controls, then seeded calibration identities. The same finite cell order is used for matched policy comparisons. Blocks, setup charges, cell charges, control charges and budgets are frozen in configuration. Each observation updates paid sufficient statistics only after a successful purchase. New interventions require setup costs; increasing depth does not. Each purchase contains previously unseen cell IDs. Legacy configurations record unused budget when a whole block cannot fit. New configurations may explicitly allow affordable partial blocks; a newly opened condition must provide at least two cells. Separate scorer controls are never predictors' paid controls.

The service's ability to request a chosen intervention's next cell block is a retrospective design abstraction. A pooled screen does not automatically offer that physical action; implementing it may require library reweighting, enrichment, sorting or arrayed work. Setup and measurement units are hypothetical accounting parameters, not verified laboratory prices. Prospective feasibility and cost must be established before claiming laboratory savings.

Current policies are:

| Policy | Executed decision rule |
| --- | --- |
| `random_equal` | Equal-depth opening/allocation with random ties, keeping a fixed control-cost fraction. |
| `fixed_grid` | Fixed control fraction and equal-depth grid with a seeded identity order. The initial defaults were untuned; a nine-point development grid is now recorded separately. |
| `diversity` | Source-feature farthest-point opening; control actions use query-variance reduction. This is a hybrid heuristic. |
| `d_optimal` | Greedy change in `logdet(M + .01 I)` per cost, with nuisance-aware shared controls. |
| `worst_query` | Greedy decrease of maximum `q'(M + .01 I)^-1 q` over the fixed source-query coordinates, per cost. |
| `mean_query` | Greedy mean query-variance reduction under the same shared-control information and support priority, per cost. Added after the controlled study as a secondary comparator aligned with average MSE. |
| `reliability` | Greedy scalar mean-variance reduction per cost, including controls. |
| `disagreement` | Query-variance reduction weighted by disagreement between two ridge resolutions fitted only to paid calibrations. |
| `bias_aware` | Worst-query variance decrease plus a weighted fixed-kernel discrepancy-variance decrease, per cost. |

Query-directed policies prioritize decreased query-span residual while some queries are unsupported. A new coordinate direction earns no coverage bonus once all fixed queries are supported. The `.01 I` design prior makes scores finite; it never changes the unregularized support diagnostic. These are block-greedy designs, not globally optimal solutions.

For the discrepancy surrogate, the unit-amplitude RBF kernel is `K_ij = exp(-mean((z_i-z_j)^2)/(2 ell^2))` on non-intercept source coordinates. Conditional variance is `K_QQ - K_QC (K_CC + C_noise + 1e-6 I)^-1 K_CQ`. The score uses its mean diagonal reduction; `C_noise` includes shared-control covariance. The default weight is .25 and length is 1. This assumes a source-smooth discrepancy and a known transfer trend. It neither learns residual amplitude nor computes the actual residual risk of the fitted ridge predictor. The predictor is still ridge, so the acquisition surrogate can be mismatched. This comparison is an explicit hypothesis, not evidence of novelty or improvement.

The initial pilots crossed all policies with zero effect, shared mean response, source copy, pooled scalar affine adaptation, low-rank ridge GLS, and local residual adaptation. The current implementation additionally includes `ridge_cv`, using only paid calibration contrasts to select a declared penalty grid. The v2 development follow-up used `[.1, 1, 10, 100, 1000]`; the controlled study expands it through 100,000 and explicitly allows a zero-effect candidate. This addition does not retroactively change the initial pilots. The scalar affine comparator uses pooled ordinary least squares. The local comparator combines source effects with reliability-shrunk neighboring paid residuals; it follows the source-query/calibration information interface but is **not a reproduction of PerturbMap**. Claims about beating the original method are unavailable.

Ordinary leave-one-intervention-out validation is optimistic when the held-out contrast and training contrasts share controls. For held-out linear prediction `a' y_train`, the implemented score is `mean_gene((y_i - a' y_train)^2) - (v_i + c) + 2 c sum(a)`, with treatment mean variance `v_i` and shared-control variance `c`. Under fixed features, fixed design, known variances and mean-zero measurement errors, its expectation equals the predictor's squared error against the true held-out effect. The term `2 c sum(a)` corrects shared-control covariance; subtracting the noise floor alone does not. This identity was checked against an independent dense-covariance Monte Carlo reference. Variances are actually estimated from paid cells and acquisition is adaptive, so the score is a plug-in selection rule without an unbiased adaptive-risk guarantee. Scores can be negative and are not clipped. All validation interventions and controls were already purchased; no scorer observations enter this procedure. Selected penalties and scores are retained with predictions.

Prediction NPZ files and their index are closed and hashed before the scorer opens held-out query/control outcomes. The runner retains a source ZIP, exact configuration, prepared-input and episode hashes, prediction hashes, ledgers, allocations and access records. Code changes during acquisition cause scoring to be refused. This is a cooperative experimental API boundary; a hostile Python process with filesystem access is outside its threat model.

Primary error is the mean squared error over all exactly aligned genes, then query interventions, at each frozen budget. The primary area is trapezoidal over the common budget grid divided by its width. It omits the unobserved interval below the first budget and uses budget ceilings; actual spend is separately recorded. Assessors estimate a mean-noise floor from independent query/control cells. Noise-subtracted error may be negative and is not clipped. Centered response-specific error is separate from absolute effects because shared errors can cancel in ranking.

Zero effect and source copy require no recipient measurements; their flat curves can be produced at recipient cost zero. Displaying them at the same budget ceilings facilitates comparison and does not imply they require the policy's purchases. Current metrics separately record the measurement cost used by each predictor, and manifests record fixed public-source and scorer-only cell resources. These resource fields were added after the initial pilot; the original ledgers and source/assessment bank maps retain their accounting. Public source data are fixed supplied inputs, not an uncharged recipient validation set.

The current paired bootstrap averages acquisition seeds within each query intervention and resamples query interventions. Its interval is descriptive and conditional on the fixed source data, split and scoring/control bank. It omits common-control, biological and batch/guide uncertainty; acquisition seeds do not increase the number of biological replicates. Gaussian coverage diagnostics use ideal unregularized scalar variance around ridge predictions: regularization bias alone can spoil coverage, even before adaptive selection, source uncertainty, heteroskedastic genes or mechanism shifts. They must not be called validated confidence intervals.

The complete controlled grid and accounted development tuning have executed. Outstanding study requirements include the integrated comparator check, frozen external evaluation, external uncertainty/permutation/ablation analyses and the final evidence-to-claim report. A successful smoke run does not satisfy those requirements.

## Controlled study additions

The [controlled protocol](controlled-study-protocol.md) fixes the scenario matrix, expanded shrinkage rule, paid variance-ratio forecast, source permutations, and six acquisition ablations. Cached nuisance-scatter and Gaussian-process updates are checked against independent dense recomputation. Named policy variants cannot change the matched pilot, costs, or prediction settings. The zero-discrepancy ablation reproduces the classical ledger.

Source stability uses public squared response norm versus twice its estimated mean measurement variance. It is a heuristic warning, not an identification or deferral guarantee. Prediction artifacts retain source noise estimates, instability flags, and a combined support/stability deferral recommendation. Known latent support and true coverage are scorer-only simulation diagnostics. Shared simulated batch effects make disjoint cells dependent in the batch stress scenario.

Study aggregation averages queries and acquisition seeds within each generative world before paired world-level Monte Carlo uncertainty. Gaussian coverage is conditional on finite-width intervals and reports its denominator. Each run records structured JSON events, current-process memory with explicit lifetime-peak scope, and the fixed development resource separately from incremental budgets. The [retention correction](retention-analysis-correction.md) documents corrected predictor-only retention ordering and denominators for the four earlier pilot reports.

For cached classical updates, let total precision be `W`, its feature center be `mu`, and centered information be `M`, including controls at zero feature. Adding precision `t` at `x` gives `M_new = M + [t/(1+t/W)] (x-mu)(x-mu)'` when `W>0`. With no previous observations the first weighted group contributes zero centered scatter. Query variances and log determinants then use rank-one inverse/determinant identities. The independent-control ablation instead uses diagonal contrast noise `v_i/n_i+c`; this intentionally wrong covariance is confined to acquisition. Gaussian-process depth/control gains use rank-one covariance downdates; a new intervention uses its Schur complement, including the shared-control off-diagonal. Dense-reference tests cover empty/partial/full calibration sets and every action type.

The [completed controlled study](controlled-study-findings.md) retains all 70 cases and demonstrates that source measurement error can make conditional numerical support misleading. The [accounted development selection](development-tuning-findings.md) chooses a fixed grid and discrepancy weight but yields near-null predictions and no useful demonstrated development gain. Its updated fixed resource is 6,344 units. These results do not validate the heuristic source deferral rule or complete external evaluation.

## Integrated comparator and analysis additions

Explicit `transfer` configuration enables two additional backbones: the paid-control recipient-local low-rank network and the single-source PerturbMap reconstruction. [The protocol](transfer-comparator-protocol.md) specifies its train-only response basis, paid validation, descriptor features, optimizer, route calibration and fidelity limitations. The default legacy configuration continues to fit seven predictors. Both added predictors share each policy's existing purchases; raw control blocks are retained only when this option is enabled. Their training/validation identities and optimizer diagnostics are stored as a non-pickled JSON scalar in the authenticated checkpoint. Adversarial scorer-query/control changes leave every prediction and ledger unchanged.

The `uncertainty` CLI executes [the paired assessment protocol](assessment-uncertainty-protocol.md): separate query, fixed-query cell and technical-batch sensitivity scopes, preserving one shared control resample. Saved float32 predictions are promoted before arithmetic to match the scorer. It checks the paired projection against the original error area. Missing batch sentinels are unavailable metadata, not extra batches. These analyses condition on fitted predictions and do not become biological confidence intervals.

The optional `source_sensitivity` setting executes [the source-half protocol](source-sensitivity-protocol.md) with the original paid observations. Its ridge displacements and support disagreements are sensitivity fields, not interval bounds. Neither source-half agreement nor the earlier source stability flag certifies true population support.

`account-development` recomputes the unique exposed cell union from frozen runs. A valid ledger hash chain alone cannot detect truncation; accounting also reconciles every configured checkpoint and final spend. New predictions additionally bind the exact ledger prefix hash and event count. Historical indexes lack this binding and receive an explicit legacy qualification. This is protection against accidental corruption within the cooperative runner model, not an adversary who rewrites all frozen hashes.
