# Publication readiness: PI review and acceptance criteria

Started October 23, 2026. This is a new goal beyond completion of the computational implementation. The current repository contains a research report and substantial evidence; those alone do not establish a submission-ready paper. The user asks for the paper, code and accompanying project to be ready for a preprint or formal submission. Journal acceptance and submission itself are separate human/editorial decisions.

Author-supplied front matter: Abdullah Hamza; Independent Researcher; abdullah2hamza@gmail.com; no external funding; no competing interests. User-selected reuse terms: MIT for original code, CC BY 4.0 for the manuscript. Original data and third-party materials retain their own terms. GitHub visibility is unchanged during preparation.

Completion requires current, inspected evidence for all of the following:

1. A self-contained scientific manuscript with accurate title, abstract, introduction/related work, estimand/task, fully specified methods, appropriate mathematical derivations, executed results, discussion/limitations, conclusions, references and author/data/code/ethics/funding/conflict disclosures. Deliver a rendered PDF, editable sources and a submission source archive, with no unresolved placeholders.
2. A substantive independent scientific/statistical review and a mathematical/code review, addressed in a response ledger. Distinguish essential repairs from optional future work. If a code error affects results, preserve the original study and transparently regenerate the affected evidence; do not hide retrospective changes or relabel post-primary work.
3. Every quantitative manuscript claim and figure/table must trace to authentic artifacts or new reproducible analysis with explicit timing and units. Check estimands, denominators, sign conventions, uncertainty units, multiplicity and baseline-selection history. Do not infer equivalence or biological population conclusions from conditional null results.
4. Establish a coherent publishable contribution supported by the actual negative/failure evidence, with a precise relationship to prior methods. Verify cited primary sources and bibliographic metadata. Document reconstructed/adapted methods without claiming reproduction of their published performance.
5. Complete any essential validity analysis found by PI/reviewer scrutiny. Preserve sealed primary predictions, make stronger-information references explicit, and distinguish fixed-bank results from biological replication and prospective economics. Cosmetic packaging cannot substitute for a scientific repair.
6. A documented reproducible manuscript build and evidence-to-figure/table pipeline; a clean environment must regenerate the manuscript's numerical summaries from manageable retained results. Include enough detail to rerun experiments from pinned public data, check a fresh install and package the precise code/configuration/dependencies. Verify relevant tests, offline commands and artifact integrity at the final source revision.
7. Reader-facing code/data availability, software and manuscript licensing, third-party attribution, citation metadata, release/package manifest and submission instructions. Prepare a shareable archive without raw datasets, credentials or machine caches. Do not change repository visibility or submit a manuscript without the user's authorization.
8. Inspect the compiled manuscript visually, resolve citation/reference/figure/table/typography defects, check archive contents and portability, and complete a requirement-by-requirement final readiness audit. Record remaining human submission actions honestly; no scientific or artifact requirement may be left unverified when the goal is closed.

Use two narrowly scoped reviewers at most concurrently, with parent-led integration. The previous goal's completion audit remains historical evidence for the implementation, not proof of these publication requirements. The publication goal remains active until the new audit passes.
