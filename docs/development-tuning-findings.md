# Development tuning findings

October 22, 2026. The [predeclared tuning protocol](development-tuning-protocol.md) evaluated nine fixed grids and five discrepancy weights, reusing classical acquisition for weight zero. All 14 unique policies completed five acquisition seeds and three budgets on the existing Frangieh development episode. This is development selection, not an external test. The run took 407.3 seconds, with a requested OpenBLAS thread limit of one. Recorded own-process peak working set was 911 MB; it includes mapped data pages and is a lifetime peak.

The [complete selection record](evidence/development-tuning-selection.json) and [all result tables](results/frangieh-tuning-v1/results.md) retain every candidate. The exact predeclared rule selected fixed control fraction `.125` with depth `8`, and discrepancy weight `1` with kernel length `1`. Their ridge-CV error areas are approximately `.002390497` and `.002390651`; classical worst-query is `.002391178`, and zero effect is `.002390449`.

The numerical ordering provides very little evidence for an allocation benefit. The selected discrepancy weight improves only about **0.022%** over classical acquisition and still loses to zero effect. Zero was selected in **163 of 210** paid validation decisions; all other decisions chose the largest finite penalty, `100000`. The exact null is now an available endpoint, while the finite shrinkage tail remains discretized. The surviving policy differences are tiny deviations from a near-null predictor, not a useful demonstrated biological improvement. Keep the procedural winners for a frozen external test and retain the original weight `.25` as a separate comparator; do not reinterpret development selection as a confirmatory result.

The [recomputed development resource](evidence/development-resource-accounting-v2.json) includes 512 unique recipient controls, 5,016 perturbed cells, and 204 opened interventions across the original pilots and this tuning run. At the common cost schedule, the fixed development total is **6,344 units**, an increase of 1,384 over the earlier 4,960-unit record. Public source cells remain a separately supplied fixed resource: 19,708 cells. The earlier record is preserved because it was frozen with the controlled simulation study before this follow-up informed any subsequent choices. Future external configurations must reference the updated record.
