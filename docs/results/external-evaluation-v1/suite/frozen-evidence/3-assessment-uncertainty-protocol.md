# Paired assessment uncertainty protocol

October 22, 2026. This specifies an additional scorer-side analysis before opening either external recipient assessment bank. Development results are already available. The controlled simulation runs retain their original source freeze while this analysis is prototyped separately.

For frozen predictions `p_A` and `p_B` of a query's `G` gene contrast, their paired squared-error difference is `D = (||p_A||²-||p_B||²)/G - 2(p_A-p_B)'(mu_t-mu_0)/G`. The quadratic term in the unknown truth cancels. Averaging acquisition seeds and integrating the common budget grid gives a constant `C_i` and vector `a_i` for each query, so `D_i = C_i - 2 a_i' mu_ti/G + 2 a_i' mu_0/G`. This identity permits exact low-dimensional projection of assessment cells, without repeatedly materializing a bootstrap-by-query-by-gene tensor.

The primary paired area estimate must equal the original metric-based paired area to numerical tolerance. Every prediction artifact, prediction index, assessment-access record, episode, and prepared input is authenticated before projection. Query order, common budgets, and acquisition seeds are matched explicitly; a missing policy artifact is an error. Known population truth is unnecessary. Predictions and acquisition decisions are never refitted using assessment cells.

Keep uncertainty scopes separate:

1. **Query-intervention bootstrap conditional on the observed bank.** Average acquisition seeds first, then resample whole query identities. This reproduces the existing descriptive query interval; neither genes nor acquisition seeds become biological replicates.
2. **Assessment-cell bootstrap conditional on the fixed queries and predictions.** Resample each query's treatment cells and the shared control cells. The same control resample is reused for all queries. Retain a version stratified by observed guide and technical batch, preserving the observed mixture. Report missing batch metadata, singleton strata, cell counts, and the independence assumption. A cell interval describes measurement sampling under that assumption; it is not a biological interval.
3. **Shared technical-batch reweighting sensitivity where labels exist.** Give every observed batch one positive exponential weight, reused across all queries and controls, and recompute condition means with their actual cell counts. Report percentile sensitivity bands and the number of observed batches. Missing or single-batch metadata cannot support this analysis. Technical batches are not assumed to be independent donors or biological replicates, and the band is not labeled a frequentist biological confidence interval.

Do not combine query and cell bootstrap intervals by naively nesting both resampling stages: observed between-query dispersion already contains treatment measurement noise. Report the separate scopes and limitations instead of asserting a calibrated joint interval. The fixed-query IID measurement variance has an independent analytic check: `4 sum_i var(t_i)/n_i / Q² + 4 var(mean_i z_i)/n_0`, where `t_i` are treatment-cell projections and each control cell's vector `z_i` contains its query-specific projections. This retains cross-query shared-control covariance. Independently resampling control cells for each query can materially understate that component.

These analyses condition on the public source responses, split, paid acquisition seeds, fitted predictions, and available assessment cells. They do not account for source estimation, policy selection, missing biological replication, protocol differences, or systematic errors in the target estimand. Compare absolute-effect error and response-specific results separately because common control error can cancel in some paired contrasts. Synthetic known-truth coverage diagnostics remain separately qualified. A negative or inconclusive result is retained.
