# Transfer comparator reconstruction protocol

October 22, 2026. Implement a single-source algorithm reconstruction from [PerturbMap, sections 4–5](https://arxiv.org/html/2607.28090). Its shared response coordinates use training identities only; validation and query source responses remain inference tokens. A recipient-local LayerNorm/128-unit/GELU network predicts latent responses from paid control correlations with 64 variable anchor genes, plus mean, standard deviation, and detection. The declared rank is 16; optimization uses batch 16, learning rate .001, weight decay .0001, three epochs per round, at most 100 rounds, and validation patience 15. A disjoint 20% paid validation split selects affine-ridge transport over .001–10, interpolation clipped to [0,1], and nonnegative relative validation reliability. A rejected route falls back to the local base. The source article's original experiment has two sources, a different cohort/gene panel, and earlier Replogle development; this project does not reproduce its reported performance.

Explicit implementation decisions resolve underspecified details: exact row-Gram PCA replaces the covariance sketch; NumPy AdamW supplies the optimizer; the ridge energy scale is the centered source Gram trace divided by latent dimension. Linear weights and biases use bounded uniform initialization. Basis rank is capped by available training rows and nonzero eigenvalues. Missing measured target-gene descriptors receive an explicit zero vector and a recorded flag. All-zero response coordinates produce a finite constant decoder. These choices are frozen for the reconstruction and remain limitations on author-code fidelity.

Every training response, validation response, and descriptor control cell must come from the same policy's paid observations. Validation cells do not receive a refund and source tokens do not include recipient query outcomes. Early stopping and route calibration can use paid validation labels; they cannot use the scorer bank. The reconstruction preserves the article's empirical validation criterion, with its limitations under shared noisy controls. Its internal validation statistics are not coverage guarantees.

The interface returns both `recipient_local_lowrank` and `perturbmap_reconstruction` so the value of transport can be compared under the same basis, optimizer, data, and budget. It also records training/validation IDs, descriptor anchors/missingness, basis hashes, optimizer rounds, ridge scores, interpolation, and reliability. This is a reconstruction with declared differences, not the existing heuristic local-residual predictor. A bounded prototype will first use an already-purchased Frangieh development ledger, adding no new unique recipient observations. Before external scoring, integrate it into the typed package, verify gradients/coordinate isolation/determinism and cost access, and freeze its configuration with the other baselines. No prior-method advantage is claimed from a prototype.
