# Pilot protocol, frozen before real-data policy scoring

October 21, 2026, America/New_York. This is a development pilot; external K562/RPE1 recipient-query results have not been scored. The full study remains governed by [the implementation objective](implementation-objective.md).

The first development direction is Frangieh's `Control` experimental context to `IFNγ`. `Control` here is a context label; negative-control interventions are separately labeled `control`. Preparation selects `MOI=1`, caps each perturbation/context at 96 cells and controls/context at 512, and retains all 23,712 input genes. Counts are explicitly normalized as described in [implemented methods](implemented-methods.md). The initial preparation captured source hashes at completion during implementation; its manifest marks this provenance caveat and exploratory status.

Eligibility requires at least 32 source cells and 96 recipient cells per intervention, with 512 recipient controls. Query identities are a seeded 25% gene-level split among eligible interventions. All guides attached to a gene follow that identity's split. Reused guide identifiers across distinct target labels cause an error. Each candidate has 64 acquisition cells and 32 assessment cells; query acquisition cells are omitted from the acquisition map. Controls split into 256 acquisition and 256 independent assessment cells. Candidate assessment cells are reserved and currently unused. The source and target cell-ID sets must be disjoint.

Budgets are `[128, 256, 512]` abstract cost units. Each new intervention costs 4 setup units plus one per cell; controls cost one per cell. Blocks have 8 cells. Every policy pays for 16 initial control cells and six seeded interventions with eight cells each: 88 pilot units. Five acquisition seeds `[0,1,2,3,4]` are run. Source rank is 4, ridge is .1, fixed control fraction .25, discrepancy weight .25 and kernel length 1. These defaults are predeclared and untuned. All eight currently implemented policies and all six predictors are included.

Primary comparison is `bias_aware` versus `worst_query` with the **same ridge predictor**, using normalized error area over the common budget grid. Positive differences mean the extension is worse. Report every comparator and all budgets regardless of sign. This pilot's five acquisition seeds establish pipeline variability; they are not five independently sampled biological datasets. The initial synthetic pilot already shows a small negative result for the extension in a linear setting, and that result is retained.

Recipient query labels open only after all predictions in the run are frozen. All scorer-only resources are reported separately. No free validation labels are supplied to the predictor or policy. No development tuning, prospective guarantee, biological replication, or advantage over an original PerturbMap implementation is claimed. The report's intervention bootstrap is conditional on one assessment/control bank; a final scientific analysis must address its stated uncertainty limitations.

For the external pair, the metadata-only audit found 525 exact gene targets with at least 96 cells in both K562 and RPE1. These identities plus controls define bounded preparation, using the published count panels (8,563 and 8,749 genes respectively), batch/guide labels preserved, 96 cells/target and 512 controls. Gene intersection and protocol compatibility remain to be reported. No external performance is used to select the pilot settings. A later external protocol and full ablations must be frozen explicitly; these preparations alone do not constitute that evaluation.
